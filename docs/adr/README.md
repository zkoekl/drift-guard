# ADRs

- [0001](0001-cli-language.md) — Go or GraalVM native-image. Superseded by 0005. The latency numbers are in 0005.
- [0005](0005-runtime-model.md) — runtime model: no daemon, two channels, four layers.
- [0002](0002-permission-gated-proposals.md) — proposals are offers. The tool does not apply or push them.
- [0003](0003-independent-verification.md) — the hook or CI checks. The coding agent does not grade itself. Phases 0–2 use no model.
- [0004](0004-metrics-runtime.md) — `drift-guard report` writes a local HTML file. No server by default. No telemetry.
