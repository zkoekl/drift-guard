# Code of Conduct

## Pledge

Participants in this project are expected to keep the community free of harassment, for everyone, regardless of age, body, disability, ethnicity, gender identity and expression, experience, education, socio-economic status, nationality, appearance, race, religion, or sexual identity and orientation.

## Expected behavior

- Critique the change, not the person.
- Accept correction. Agents and people miss things.
- Do not publish anyone's private information. If a pull request adds a name, an address, an employer, or a secret, maintainers will remove it.

## Unacceptable behavior

- Harassment, insults, and sexualized language.
- Posting private personal data, credentials, or unredacted session logs.
- Using the issue tracker to dump raw agent transcripts that contain names or secrets.

## Scope

This applies to issues, pull requests, and any other space where someone is representing the project.

## Enforcement

Maintainers may edit or reject issues and pull requests that break this policy, and may block further interaction for repeated violations.

Report a conduct or privacy problem through a private GitHub security advisory on this repository. Do not file a public issue that repeats the private data.
